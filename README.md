# Also sprach Zarathustra — Talmudische Ausgabe

Interactive Talmudic-style web reader of *Also sprach Zarathustra* with
aligned DE / EN / FR / ES translations and a layered commentary stack
(Klossowski, Deleuze, Sánchez Meca, New Cambridge Companion, Sánchez
Pascual introduction & translator notes, and a hand-curated philology
stream).

## Layout

- `source/` — PreTeXt XML chapter files, chapter-nav, and the
  `commentary.json` sidecar consumed by the reader.
- `scripts/` — build / parse / RAG retrieval / alignment / translation /
  validation pipeline.
- `web/` — the live reader (`talmud.html` + `talmud.js` + `style.css`).
  Reads `source/*.ptx` and `source/commentary.json` directly at runtime.
- `output/web/` — generated by `pretext build web`; this is a
  **validation artifact** to confirm the PreTeXt source is well-formed.
  It is NOT the live reader and is git-ignored.

## Pipeline

```
build_chapters.py        DE/EN/FR Gutenberg → chapters/*.ptx
parse_spanish.py         Sánchez Pascual PDF → ES paragraphs (1:1 patch)
align_es_via_embeddings  LaBSE many-to-one DP re-alignment of ES
parse_es_notes.py        Sánchez Pascual footnotes → sanchez-pascual-notes stream
retrieve_commentary.py   Per-verse RAG over 5 corpora
translate_commentary.py  Translate cross-lingual notes (Gemini 2.5-flash)
validate_commentary.py   Schema validation
snapshot.py              Golden-hash drift detection
```

## Quality gates

- `python scripts/validate_commentary.py` — schema + sanity checks
- `python scripts/snapshot.py` — golden-hash regression test
- `pretext build web` — source XML validation
